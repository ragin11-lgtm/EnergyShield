# Resume and Recruiter Material

## Project Title

**EnergyShield — Energy Infrastructure Cybersecurity Monitoring & Incident Response Lab**

## Resume Bullet Options

- Built a Python-based defensive SOC simulation that normalizes 75 fictional energy-sector security events and applies 10 explainable authentication, network-reconnaissance, privilege, access, and malware detection rules.

- Designed a deterministic 0–100 risk engine with privileged-account and OT-system context, conservative MITRE ATT&CK enrichment, and defensive incident-response playbooks with availability-aware OT cautions.

- Developed a Streamlit/Plotly dashboard with alert filtering, seven security visualizations, drill-down evidence, and Markdown incident reporting; added pytest coverage for rule thresholds, correlation, scoring, and malformed JSON handling.

## Short LinkedIn Project Description

EnergyShield is my beginner-friendly Python cybersecurity portfolio lab for a fictional energy company. It converts 75 safe local JSON events into explainable SOC alerts, contextual risk scores, MITRE ATT&CK mappings, and incident-response guidance, then presents the results through a CLI and interactive Streamlit dashboard. All activity is simulated; the project does not scan networks or interact with real industrial systems.

## Approximately 30-Second Recruiter Explanation

“I built EnergyShield to connect my Python learning with defensive cybersecurity. It simulates a small SOC for a fictional energy company using 75 local JSON events. The application detects patterns such as repeated failed logins, privileged-account attacks, simulated port scans, rapid multi-host contact, privilege changes, and malware alerts. It adds an explainable risk score, MITRE context, and response steps, and displays everything in a CLI or Streamlit dashboard. It is completely simulated and does not control or contact real energy systems.”

## Accuracy Notes

Do not describe EnergyShield as:

- protecting a real grid or utility;
- a production SIEM;
- a live SOC deployment;
- an ICS/SCADA implementation;
- machine-learning detection;
- real threat-intelligence integration; or
- evidence of incident-response experience in a production environment.

It accurately demonstrates Python, JSON handling, rule-based detection, basic event correlation, contextual scoring, ATT&CK awareness, incident-response planning, dashboard development, and testing in a safe lab.
